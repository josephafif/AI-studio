# Logitlins – var i modellen bestämmer sig Lennart?

`logitlins.py` läser av modellens mellanläge efter varje lager genom slutnormaliseringen och
utmatningen, och räknar en *lagerbrygga* (linjär avbildning, ridge-regression i sluten form) från varje
lager till slutlagret. Resultat i `resultat_lennart34.json` och `../RAPPORT.md`, avsnitt 4.
